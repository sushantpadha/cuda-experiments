# Look-ups (tracker goal 2)

One folder per tracker item, each with a `FINDINGS.md`. Probe code and exact commands live in `experiments/lookups/<item>/`.

- `2A-compute-sharing/`: MPS vs. green contexts for spatial compute sharing; VMM, handle export and host fallback under MPS; fault propagation.
- `2B-eviction-metrics/`: kernel-argument working sets (LD_PRELOAD vs. CUPTI injection), kernel time vs. demoted fraction, GPU-side block hashing, hardware access counters.
- `REVIEW.md`: independent check of both, by a separate agent.
